# Freelance OS 1.4.0 release verification

Date: 2026-10-24. Base commit: `4ad9e29016610b3c51ed989086064a28862b9c2c`.

The user authorized fixing all five independent-audit findings, fresh-save verification, regression checks, production deployment and release. This record supersedes the release-blocking status in the earlier audit; that report remains unchanged as historical evidence.

## Scope and audit resolutions

The release includes the previously implemented A–E workflows: native waiting explanations and resume, scoped queue presets/counts, weekly-review discovery and explicit carry-forward, contextual project capture, and optional evidence-backed project suggestions. It does not add collections, time tracking, billing features or required third-party plugins. Structured prerequisite-task dependencies remain deferred.

| Finding | Resolution | Main integration points |
| --- | --- | --- |
| F1: stale reconciliation can remove a newer next-action reference | Validate the generation/mutation version after awaited reads and before writes; compare the current marker content against its captured value; revalidate resumed tasks; commit pointer maps only after successful native reconciliation. A stale run leaves the last good pointers intact. | `src/workflow.js`: `workflowSnapshotCurrent`, `applyWorkflowSnapshot`, native reconciliation, `writeNativeNextAction`, `pruneNativeNextActionSection` |
| F2: missing capture destination silently becomes Journal | Preserve the intended project GUID and show an explicit disabled unavailable option. Reject Save while it is unavailable, retain the draft and require an actual destination selection. | `src/index.js`: capture destination rendering and Save handler |
| F3: unsafe live regression ownership/cleanup | Require the exact test workspace and plugin before mutation. Create and immediately register an owned project and reserved review headings; clean only their owned subtrees, including interrupted pending saves. Restore exact raw local state and compare existing Project/Journal content against its baseline. | `test/live-workflow.mjs`, `test/live-safety.mjs`, `test/live-safety.test.mjs` |
| F4: carry provenance lost during normalization | Validate and retain `carriedFrom` when normalizing saved priority items. Invalid provenance is discarded without removing the priority. | `src/workflow.js`: `normalizeWorkflowState` |
| F5: waiting editor loses typed values on save failure | Keep reason/date drafts in memory across rerenders and failures; clear only the values successfully saved, retaining any newer edits. | `src/index.js`: waiting draft helpers, waiting row rendering and save handlers |

Strengthened three-week live verification also exposed stale SDK line wrappers during origin-marker checks. Review saves now re-read the known source record/line before deciding whether an origin marker is missing. Later review saves preserve the original marker.

- An injected body-write failure registered the pending heading immediately. Retry used that same heading; cleanup removed its owned subtree.
- Actual capture/waiting UI handlers rejected an unavailable destination, recovered after explicit Journal selection, retained waiting text after a failed save and saved that retained text on retry.
- Native next action, focus limit and waiting/resume live checks passed.
- Native panel widths of **1141, 569 and 379 px** had no detected horizontal overflow. Screenshots were inspected; the design detector returned no findings in the edited source files.
- Workflow cleanup reported one owned project, four owned review sections, exact raw-state restoration, unchanged unrelated records and no failures. Fixture records were trashed rather than permanently deleted.
- The existing record-creation runner passed under an outer explicit test identity guard with raw-state restoration. Client, project, invoice and support-session creation regressions passed.
- The collection-view runner passed all 16 view checks under the same test-only boundary. It checked invoice, project, client and support-session views.
- `git diff --check` passed. `.pi/` is ignored by the root `/.pi/` rule and has no tracked files.

The earlier first-save failure was not treated as resolved merely because retry worked: the replacement runner separately verified a clean first save and an injected partial-save retry on owned dates. No live fixture mutations were run against production.

## Remaining limits

- No second physical device was used. Native synced data paths and deterministic race tests were checked, but distributed concurrent creation remains subject to the SDK's lack of transactions or compare-and-swap.
- Review snapshots represent the last explicit Freelance OS save, not later manual edits to review prose. Duplicate review sections require user selection.
- This verification did not perform a full screen-reader, pixel-contrast, light-theme or keyboard-only audit. Responsive checks and draft/error behavior are narrower evidence.
- Journal discovery-cache invalidation on remote-only changes remains a follow-up risk from the independent audit; no new reproduced failure was established during this release pass.
- Structured blocker graphs and automatic readiness/resume remain deferred product work.

Release installation files: `dist/freelance-os-backup.json` and `dist/freelance-os-starter.json`. They contain the plugin/starter definitions, not the private production backup or workspace workflow state.
