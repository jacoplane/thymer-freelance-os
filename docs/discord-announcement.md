# Discord announcement draft

I’ve been building **Freelance OS**, a dashboard for running a small freelance business inside Thymer.

It brings together a business overview, clients and projects, invoice/payment tracking, project next actions, a three-task daily focus, and a guided weekly review that saves to Journal. Everything uses native Thymer records and tasks, and it adapts to split panels.

The repo now includes setup instructions, a starter configuration for an empty workspace, a usage guide, and screenshots from a separate workspace with fictional data. No Daily Focus or other third-party runtime plugins are required.

It’s an early community version. Financial totals currently use CHF, and focus selections/review drafts are local to each device. I’d love feedback on the workflow and the installation experience.

https://github.com/jacoplane/thymer-freelance-os
